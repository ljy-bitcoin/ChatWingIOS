# 真机验收（交付时尚未执行）

在你的 Xcode、iPhone 和模型账户上填写结果。先完成签名和共享能力，不要用模拟器结论替代实时录屏测试。

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 构建 | Xcode Run / Product Test | 主 App、两扩展均编译；单元测试通过 |
| 共享配置 | 保存联系人与 Key，重启 App | 设置可恢复，无 App Group 或 Keychain 错误 |
| 接口 | 粘贴两行对话进行分析 | 返回真实判断和三条不同候选；错误清楚显示 |
| Jev 排序失败 | 用无法排序的测试接口响应 | 回复保留；标注未经排序，不显示假的概率 |
| 截图 | 选自己的一对一聊天截图 | 标题、消息顺序、左右侧可核对，图像未上传 |
| 录屏 | 开启会话、系统广播，再切微信 | 广播持续采样；不使用麦克风；主程序有新结果 |
| 标题门控 | 打开另一个聊天或设置页 | 停止模型调用，撤销候选 |
| 画中画 | 开小窗后在微信停留超过2分钟，产生新消息 | 小窗继续刷新，不只是留有旧画面 |
| 去重 | 停留同一屏一分钟 | 无重复成功请求；失败重试有退避 |
| 滚动 | 快速上下滚动历史 | 不积压大量请求；画面稳定后才分析 |
| 暂停竞态 | 请求未返回时点暂停 | 旧请求返回后不能重新显示/插入候选 |
| 换联系人 | 分析中切联系人并重新开启 | 旧联系人的结果不能覆盖新会话 |
| 结果过期 | 同屏停留超过3分钟 | 候选过期，键盘不能插入旧回复；需新会话或新内容 |
| 键盘 | 允许完全访问并切换，点候选 | 只插入选中文字；不点发送、不操作别的控件 |
| 已有草稿 | 输入框已有文字时点候选 | 阻止追加并提示核对，不能误覆盖原文 |
| 小窗遮挡 | 将画中画拖入识别区 | 调整区域后恢复；不得将自身候选反复当聊天 |
| 锁屏/暂停 | 锁屏、恢复、停止录屏 | 旧结果撤销；心跳过期后不可插入 |
| 资源 | 用 Xcode Instruments 运行10分钟 | 记录扩展内存峰值、CPU、耗电，无系统强杀 |

实际复现时记录：iOS / Xcode 版本、机型、聊天 App 版本、当前联系人标题、ROI 设置、广播心跳是否新鲜、PiP 是否 active。不要在错误报告中附 API Key。
